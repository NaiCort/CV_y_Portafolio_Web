# Estado de V4.7.8

Rubor, Prisma y Umbral comparten un reproductor ambiental con una pista original local en bucle. El primer acceso es silencioso. La preferencia se guarda en el navegador. Si se bloquea la reanudación automática, el control permite activarla manualmente. Privacidad detiene el audio y restablece volumen y preferencia.

Siguiente fase: refinamiento visual. Después: accesibilidad de PDF, rendimiento, pruebas integrales, teléfono físico y documentación de cierre.
